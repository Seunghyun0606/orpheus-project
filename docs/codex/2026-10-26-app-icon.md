# Codex brief C2 — app icon and Windows program details (2026-10-26)

Branch `codex/app-icon`. Read `AGENTS.md` ("Claude and Codex") first. Game code stays
unchanged.

1. **Icon.** Generate an app icon with your image generation tool in the style of
   `godot/assets/portraits/` and `godot/assets/acts/`: a single bold mark that reads at 16×16 —
   for example the calm amber lens of ORPHEUS on near-black (#0b0e0c, amber #ffb347), or a pager
   glyph. No text or letters. Produce `godot/icon.png` (512×512) and `godot/icon.ico` (16, 24,
   32, 48, 64, 128, 256), and set `application/config/icon` in `godot/project.godot` so the window
   and taskbar use it. Keep the existing `icon.svg` unless it is unused afterwards; say which.
2. **Windows executable.** In `godot/export_presets.cfg`, set the exe icon and file details:
   product and file description "The Orpheus Project", version 0.1.0 (match `package.json`). Do
   not invent a company, copyright holder or publisher; leave those empty. Embedding the icon in
   the exe needs rcedit: if it is missing, download the official `electron/rcedit` release
   into `.qa/tools/rcedit/`, record its version and SHA-256, configure it for the export only
   (not in committed editor settings), and document the step in README. Without rcedit, stop at
   the project icon and report.
3. **Verify.** `npm run godot:build`, check the exe shows the icon in Explorer
   (`[System.Drawing.Icon]::ExtractAssociatedIcon`) and its version info
   (`(Get-Item exe).VersionInfo`), boot it once in an isolated copy as in
   `docs/qa/2026-10-26-windows-build.md`.
4. Add the icon to `docs/ASSET_AND_LICENSE_INVENTORY.md` (generated image, open terms item).

Report `docs/qa/2026-10-26-app-icon.md` with the files, sizes, prompts and checks.
